# prueba-captcha

Generator, dataset and results for the poster/extended abstract *"Can Current AI Solve CAPTCHAs? What It Says About Machine Intelligence"* (WAIMLAp 2026).

Online human test: https://diana119-collab.github.io/prueba-captcha/ (`index.html`): main menu with four tests (`?set=niveles`, `?set=entornos`, `?set=libreria`, `?set=libreria2`).

## Contents
- `generator/` – Python (Pillow) CAPTCHA generator and solvers.
  - `pilot.py`, `pilot2.py`: generator and Tesseract baselines; `python3 pilot2.py OUTDIR` rebuilds the 5-level set (seed 31415).
  - `make_environments.py`: builds the three held-out environments (`python3 make_environments.py OUTDIR`).
  - `make_library_env.py`: renders the real-library environment with django-simple-captcha 0.7.1 (default settings, seed 7010203).
  - `make_library2_env.py`: renders the second real-library environment with multicolorcaptcha 1.2.0 (default settings, 4 digits, seed 20261104).
  - `train_crnn.py`: CRNN+CTC trained on generated images (`--n_train 50000 --epochs 60`; `--test_dir`, `--env_dir`, `--lib_dir`, `--lib2_dir`, and `--seeds 1,2,3,4,5` for seeded repeated runs, `--outdir` for the output folder).
- `dataset/levels/`: 200 images (levels N1–N5, 40 each) + `key.json` (ground truth).
- `dataset/environments/`: 120 images (E1 new fonts, E2 six characters, E3 inverted colours; 40 each, N3 difficulty) + `key.json`.
- `dataset/library/`: 40 images generated by the open-source library django-simple-captcha (4 letters, default settings) + `key.json`. Human test: `?set=libreria` (20 of these images).
- `dataset/library2/`: 40 images generated by the open-source library multicolorcaptcha (GPLv3; 4 digits, default settings) + `key.json`. Human test: `?set=libreria2` (20 of these images).
- `results/`: per-image predictions of every solver (Tesseract raw/preprocessed, multimodal LLM, CRNN, humans). Human data are anonymised (P1–P6 levels, P7–P12 environments, P13–P18 library set; adults, no personal data).

## Level parameters
| Level | max rotation (°) | letter spacing (px) | lines | noise dots | warp amp. (px) | blur σ |
|---|---|---|---|---|---|---|
| N1 | 5 | +4 | 0 | 0 | 0 | 0 |
| N2 | 10 | +2 | 2 | 40 | 2.0 | 0 |
| N3 | 20 | −2 | 4 | 120 | 3.5 | 0.4 |
| N4 | 28 | −5 | 6 | 200 | 4.5 | 0.6 |
| N5 | 35 | −8 | 7 | 250 | 5.0 | 0.8 |

All images: 32-symbol alphabet (no I, O, 0, 1), 5 characters (6 in E2), 310×80 px (370×80 in E2).

## Notes
- CRNN training is not seeded; three 60-epoch runs gave different accuracies on the levels (67/200, 33/200 and 83/200: `crnn_levels_run1.csv`, `run2`, `run3`). The reported numbers (abstract and poster) are from run 3, which is the only run that also covers the library set (`crnn_library_run3.csv`) and the environments (`crnn_environments_run3.csv`).
- Synthetic CAPTCHAs only; no real site was accessed.
